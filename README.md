# 🍴 Andy Demo Fork

Repositorio de práctica para aprender a hacer **Fork** en GitHub. Es una app de
Next.js mínima e interactiva: ideal para clonar, modificar y ver tus cambios en
vivo. ¡No necesitas saber Next.js para usarlo!

## Cómo hacer fork de este repo

1. Haz click en el botón **Fork** (arriba a la derecha en GitHub). Esto crea una
   copia del repositorio en TU cuenta.
2. Clona **TU** fork (reemplaza `TU-USUARIO` por tu usuario de GitHub):

   ```bash
   git clone https://github.com/TU-USUARIO/andy-demo-fork.git
   ```

3. Entra a la carpeta del proyecto:

   ```bash
   cd andy-demo-fork
   ```

4. Instala las dependencias:

   ```bash
   npm install
   ```

5. Arranca el servidor de desarrollo:

   ```bash
   npm run dev
   ```

6. Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

## 🎯 Reto

Abre el archivo `app/page.tsx` y cambia el texto del título
(`🍴 Andy Demo Fork`) por el que tú quieras. Guarda el archivo y mira cómo el
cambio aparece **al instante** en el navegador, sin recargar la página. 🚀
